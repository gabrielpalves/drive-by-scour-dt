# Manuscript figures (F25 paper)

All figures are generated by scripts in the repository. Schematics explain
geometry and operations; they contain no simulated responses or results.
PDFs are included by LaTeX; PNGs are previews and SVGs keep editable vector
geometry. Labels use English to match the manuscript. Figure titles and
caveats live in the LaTeX captions, not inside the drawings.

## Schematics

From the repository root:

```powershell
python plotting/build_paper_model_figure.py
python plotting/build_paper_architecture_figures.py
```

- `ttbi_model` (Fig. 1): five-vehicle train and the six responses of the
  leading vehicle (CV, CP, FV, FP, RV, RP), track model, and the 2 × 19.95 m
  bridge with the scour spring, entrance-bearing rotational spring and crack
  zone (29.70–30.00 m). Sources: `core/f25_experiment_contract.py`,
  `scour_MATLAB/TrainProp_ObrienCalibrate.m`, `paper1/sections/numerical_model.tex`.
  `--regression` draws the former F40/L99 version into `paper_regression/figures/`.
- `f25_architecture` (Fig. 2): preprocessing and the RAW-CNN, PAA-CNN and
  PAA-MR arms. Sources: `core/f25_models.py`, `paper1/sections/methodology.tex`.
  The same script writes `regression_architecture` into
  `paper_regression/figures/` (four-block draft only).

## Result figures

`f25_singles` (boxplots of the 20-run distributions), `f25_pairs` and
`f25_confusion` are regenerated, together with every table in `../tables/`,
by:

```powershell
python analyze_f25_results.py --archive f25.zip
```

Means are rounded half-up from exact ratios (binary float formatting rounds
values such as 72.285 down). Manuscript channel codes map to the archive codes
as CV=S00, FV=S01, RV=S02, CP=S05, FP=S06, RP=S07; the CSVs in `results/f25/`
keep the archive codes. See `results/f25/README.md` for the archive identity
and statistical scope. Recompile `paper1/main.tex` after regenerating any
figure or table.
