# Manuscript figures

All new model and architecture diagrams are vector schematics generated from
the implemented model and manuscript methods. They do not contain invented
measurements, synthetic curves presented as results, or unexecuted results.
PDFs are included by LaTeX; PNGs are previews and SVGs preserve editable vector
geometry. Labels use English to match the manuscript.

## Model and architecture schematics

From the repository root, regenerate with:

```powershell
python plotting/build_paper_model_figure.py
python plotting/build_paper_architecture_figures.py
```

- `ttbi_model`: leading-vehicle responses, planar coupling and the two planned
  bridge geometries. Source: `scour_MATLAB/D01_DataProcessing.m`, the channel
  contract in `core/f25_experiment_contract.py`, and
  `paper1/sections/numerical_simulation.tex`. The vehicle layout is schematic;
  wheelset masses have constrained motion, and S03/S04 are diagnostics excluded
  from learning. F25 has a distinct 39.9 m geometry.
- `regression_architecture`: the prospective 16-cell RAW/PAA × positional
  encoding × LSTM × pooling design. Sources: `core/models.py`,
  `core/preprocessing.py`, and `paper1/sections/data_processing.tex`.
  The historical Space2Vec name denotes the implemented Time2Vec-style spatial
  encoding; N-HiTS denotes the inspired pooling component, not a full forecasting
  network. This diagram does not report completed four-block results.
- `f25_architecture`: the executed F25 RAW-CNN, PAA-CNN, and PAA-MR arms.
  Sources: `core/f25_models.py`, `core/f25_experiment_contract.py`, and
  `paper1/sections/f25_methods.tex`. Min–Max scaling precedes PAA; S03/S04,
  positional encoding and LSTM are excluded. F25 flattening is different from
  the GAP baseline in the prospective regression design.

## Result figures

`f25_singles`, `f25_pairs`, and `f25_confusion` are regenerated by:

```powershell
python analyze_f25_results.py --archive f25.zip
```

These figures derive from the returned metrics, not the schematic scripts.
See `results/f25/README.md` for the archive identity and statistical scope.
Recompile `paper1/main.tex` after regenerating any included figure.
